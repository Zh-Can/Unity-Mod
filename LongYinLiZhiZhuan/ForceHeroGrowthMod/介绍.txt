                        门派弟子成长Mod v5.0
═══════════════════════════════════════════════════════════════

【简介】
这是一个《龙隐立志传》的MelonLoader模组，让游戏中的角色在过月时自动成长，
减轻玩家的培养负担，增强NPC战力。

═══════════════════════════════════════════════════════════════
【功能特点】

一、技能自动升级（v4.1优化）
  • 优先升级装备的武学（内功、轻功、绝技、攻击技能）
  • 装备武学升级规则：
    - 天赋允许升级：按配置等级升级
    - 天赋不允许升级：保底升1级
  • 非装备武学升级规则：
    - 天赋允许升级：按配置等级升级
    - 天赋不允许升级：不升级
  • 技能满级(10级)后不再升级
  • 每月每个角色只升级一个技能
  • 玩家角色单独配置，且会检查突破障碍

  武功稀有度说明：
    0 = 基础(白色)
    1 = 进阶(绿色)
    2 = 上乘(蓝色)
    3 = 秘传(紫色)
    4 = 顶级(橙色)
    5 = 绝世(红色)

  默认配置示例(天赋4-究极)：
    基础武功：每月升4级
    进阶武功：每月升4级
    上乘武功：每月升3级
    秘传武功：每月升2级
    顶级武功：每月升1级
    绝世武功：每月升1级

  装备武学保底示例(天赋0-愚钝)：
    装备的基础武功：每月升1级（天赋允许）
    装备的进阶武功：每月升1级（天赋不允许，但保底）
    非装备的进阶武功：不升级（天赋不允许）

二、藏经阁技能学习
  • 角色会自动学习所属门派藏经阁中的武功秘籍
  • 根据武功稀有度消耗功绩：
      基础武功：20功绩
      进阶武功：40功绩
      上乘武功：80功绩
      秘传武功：160功绩
      顶级武功：320功绩
      绝世武功：640功绩
  • 功绩不足时不会学习
  • 每月每个角色只学习一个技能
  • 人物身份不同有功绩上限限制，理论上亲传弟子功绩上限是800就可以学绝世武学

三、江湖武学学习（v3.0新增）
  • 当藏经阁武学全部学完后，自动学习江湖武学
  • 江湖武学：无门派武学（belongForceID = -1）
  • 按身份等级从高到低学习：
      身份等级5 → 学习绝世武学
      身份等级4 → 学习顶级武学
      身份等级3 → 学习秘传武学
      身份等级2 → 学习上乘武学
      身份等级1 → 学习进阶武学
      身份等级0 → 学习基础武学
  • 隐藏武学（hide = true）不会学习
  • 每月每个角色只学习一个技能

四、秘籍自动入库（v4.0新增）
  • 过日时，非玩家门派的掌门/副掌门会将已学会且≥4级的武学秘籍自动放入藏经阁
  • 4级可配置（v5.0新增）
  • 避免NPC身上堆积已学会的秘籍，提高资源利用率
  • 入库时会记录日志，可在角色日志中查看

五、学习限制（v4.0新增）
  • 可启用学习限制：人物有未满级武学时，不会学习新武学
  • 让人物先精通现有武学，避免贪多嚼不烂
  • 适用于藏经阁学习和江湖武学学习

六、处理范围选择
  • 特殊人物(默认)：只处理ID 1-170的特殊角色
  • 全部人物：处理游戏中的所有角色
  • 星标人物(v5.0新增)：只处理玩家标记为星标的人物

七、玩家特殊处理
  • 玩家可单独配置升级规则(不受天赋限制)
  • 玩家升级时会检查突破瓶颈障碍
  • 可选择是否包含玩家在自动升级中
  • 玩家不会自动学习藏经阁和江湖武学

八、详细日志
  • 可开启详细日志查看每月处理情况
  • 除了玩家，NPC所有升级和学习记录都会保存在角色日志中

═══════════════════════════════════════════════════════════════
【配置文件】

配置文件位置：UserData\ForceHeroGrowth.cfg

配置项说明：

【功能开关】
  EnableSkillUpgrade = true              (启用技能自动升级)
  EnableLibrarySkillLearn = true         (启用藏经阁技能学习)
  EnableJianghuSkillLearn = false        (启用江湖武学学习，v3.0新增)
  EnableMoveBookToStorage = false        (启用秘籍自动入库，v4.0新增，掌门或副掌门身上有秘籍，并且已经学会，且掌握等级>=配置等级时会自动放入藏经阁，过天检查)
  MoveBookToStorageMinLevel = 4          (秘籍入库掌握等级门槛，v5.0新增，已学会秘籍的掌握等级>=此值才会放入藏经阁，默认4级)
  EnableSkillLearnLimit = true           (启用学习限制，v4.0新增，如果有未满级武学，就不会从藏经阁学习或学会江湖武学)
  EnableDetailedLog = false              (启用详细日志)

【处理范围】
  HeroProcessRange = 0                   (0=特殊人物1-170, 1=全部人物, 2=星标人物)
  IncludePlayerInUpgrade = false         (是否包含玩家在升级中)

【天赋升级配置】
  格式：稀有度=升级数,稀有度=升级数,...
  
  Talent0UpgradeConfig = 0=1,1=1,2=0,3=0,4=0,5=0  (愚钝)
  Talent1UpgradeConfig = 0=1,1=1,2=1,3=0,4=0,5=0  (平平)
  Talent2UpgradeConfig = 0=2,1=2,2=1,3=1,4=0,5=0  (聪慧)
  Talent3UpgradeConfig = 0=3,1=3,2=2,3=1,4=1,5=0  (超群)
  Talent4UpgradeConfig = 0=4,1=4,2=3,3=2,4=1,5=1  (究极)

【玩家单独配置】
  PlayerUpgradeConfig = 0=1,1=1,2=1,3=1,4=1,5=1  (玩家)

═══════════════════════════════════════════════════════════════
【配置示例】

例1：让究极天赋的角色全面发展
  Talent4UpgradeConfig = 0=3,1=3,2=3,3=2,4=1,5=1
  
例2：让玩家只升级低级武功
  IncludePlayerInUpgrade = true
  PlayerUpgradeConfig = 0=5,1=3,2=1,3=0,4=0,5=0
  
例3：关闭自动升级，只保留藏经阁学习
  EnableSkillUpgrade = false
  EnableLibrarySkillLearn = true

例4：启用江湖武学学习（v3.0）
  EnableLibrarySkillLearn = true
  EnableJianghuSkillLearn = true

例5：启用秘籍自动入库（v4.0）
  EnableMoveBookToStorage = true

例6：关闭学习限制，让NPC尽情学习（v4.0）
  EnableSkillLearnLimit = false

【安装方法】

1. 确保游戏已安装MelonLoader
2. 将 ForceHeroGrowthMod.dll 放入游戏目录的 Mods 文件夹
3. 启动游戏，Mod会自动加载
4. 首次运行会在 UserData 文件夹生成配置文件

═══════════════════════════════════════════════════════════════
【注意事项】

  • 技能升级和学习都会在角色日志中留下记录
  • 玩家角色遇到突破障碍时不会自动升级
  • 建议先备份存档再使用
  • 修改配置后需要重启游戏生效
  • 秘籍入库功能默认关闭，需要手动开启
  • 学习限制功能默认开启，如需关闭请修改配置

【更新日志】
v5.0
  + 添加秘籍入库掌握等级门槛配置
    * 新配置项：MoveBookToStorageMinLevel（默认4级）
    * 可自定义已学会秘籍需要达到的掌握等级才会放入藏经阁
    * 原固定4级改为可配置
  + 添加星标人物处理支持
    * HeroProcessRange = 2 时只处理星标人物
    * 星标人物：玩家在游戏中标记为星标（感兴趣）的人物
    * 方便玩家重点关注特定角色的成长
v4.1
  + 优化技能升级逻辑：优先升级装备武学
    * 装备武学包括：内功、轻功、绝技、攻击技能
    * 每月优先检查装备的武学，有可升级的则优先升级
  + 装备武学保底机制：天赋不允许时仍升1级
    * 如果自定义天赋配置允许升级(upgradeCount>0)：按配置等级升级
    * 如果自定义天赋配置不允许升级(upgradeCount<=0)：保底升1级
  + 非装备武学受天赋限制：天赋不允许时不升级
    * 只有天赋配置允许时才会升级

v4.0
  + 新增秘籍自动入库功能
    * 过日时检查非玩家门派的掌门/副掌门（身份等级>=5）
    * 如果身上有已学会且掌握等级>=配置等级（默认4级）的秘籍，自动放入藏经阁
    * 避免NPC身上堆积已学会的秘籍，提高资源利用率
    * 入库时会记录日志，可在角色日志中查看
  + 新增学习限制功能
    * 开启后，如果人物存在未满级的技能，则不会学习新技能（藏经阁学习和江湖武学学习）
    * 让人物先精通现有武学，避免贪多嚼不烂
  + 优化代码性能

v3.0
  + 新增江湖武学学习功能
    * 当藏经阁武学全部学完后，自动学习江湖武学
    * 江湖武学指无门派武学(belongForceID = -1)
    * 按当前人物的身份等级从高到低学习，隐藏江湖武学不会学习
  + 优化配置项格式
  + 修复身份等级超过5的问题

v2.0
  + 新增玩家单独配置
    * 玩家天赋固定为0，但可单独配置升级规则
    * 不受NPC天赋配置影响
  + 新增突破障碍检查
    * 玩家升级时会检查是否遇到突破瓶颈，需要突破时不会自动升级
  + 优化日志记录
    * 添加详细日志开关
    * NPC升级和学习记录保存在角色日志中

v1.0
  + 初始版本
  + 技能自动升级功能
  + 藏经阁技能学习功能
